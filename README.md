# Gemensamma ärendemallar

Svenska ärendemallar för Ammocenter/Armtac:

- **Bugg** – problem, reproduktion, önskat beteende och acceptanskriterier.
- **Uppgift** – bakgrund, mål, avgränsat arbete och verifiering.
- **Funktionsförslag** – användarbehov, önskat beteende och acceptanskriterier.
- **Utredning** – öppna frågor, underlag och rekommendation före genomförande.

Använd en konkret titel, gärna `Område: beskrivning`. Anpassa innehållet efter ärendet och ta bort avsnitt som inte behövs. Länka beroenden och arbete i andra repon när det är relevant. Ett tomt ärende kan fortfarande skapas.

Mallarna i `.github/ISSUE_TEMPLATE/` används som organisationsstandard i repon som saknar egna ärendemallar eller egen mallkonfiguration. Ett repos egna mallar eller `config.yml` ersätter hela den gemensamma uppsättningen. Mallarna anger inga fasta etiketter eller ansvariga, så att de kan användas i olika repon.

Detta repo är publikt eftersom GitHub kräver det för gemensamma organisationsmallar. Lägg endast generellt mallinnehåll här, utan interna ärendeexempel eller känsliga uppgifter.
